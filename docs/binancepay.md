# 币安 Pay 收款

通过**币安 Pay**（Binance Pay）收款：用户在币安 App 内直接向你的币安账号转账 USDT，
**零手续费、即时到账**（币安内部转账，不经过区块链，因此没有链上确认环节）。

本功能使用**个人只读模式**：只拉取你的收款流水，不涉及任何商户下单接口。

## 原理

币安 Pay 内部转账不会产生链上交易，所以传统的「扫块比对金额」无法使用。
本项目的做法与 [BinancePayTool](https://github.com/qianyubtc/BinancePayTool) 一致：

1. 收银台为每笔订单生成一个**唯一金额**（在订单金额上按原子精度递增，保证同一时刻不会有两笔订单金额相同）
2. 后台定时拉取币安收款流水，找到「金额完全相等且在订单支付时间窗内」的入账
3. 命中即视为支付成功，直接回调商户

## 开启步骤

### 1. 创建只读 API Key

登录币安官网 → 管理 → API 管理，创建一个**只读**权限的 API Key（无需开启提币权限），
记录下 `API Key` 与 `Secret`。

> 请注意：币安个人账号商户 API 已停止开放，本功能仅使用个人账号的 Pay 流水查询接口。
> 使用个人收款接口存在币安风控与合规风险，请自行评估后使用。

### 2. 后台填写凭证

进入 **后台 → 基本设置 → 基本信息**，填写：

| 配置项 | 说明 |
|---|---|
| 币安 Pay API Key | 上一步创建的 API Key |
| 币安 Pay API Secret | 上一步创建的 Secret |
| 币安 Pay 轮询间隔 | 流水扫描间隔（秒），推荐 `30` |

留空 API Key / Secret 即视为**未启用**，任务会空转不请求币安接口。

### 3. 添加收款钱包

进入 **后台 → 钱包管理 → 新增钱包**：

- 交易类型：`USDT・Binance Pay`
- 钱包地址：填写你的**币安 UID**（纯数字，例如 `387453979`）

添加后该收款方式会自动出现在收银台的支付方式列表中。

## 工作原理细节

- 订单金额即指纹：同一 UID 下，等待支付/确认中的订单不会被分配到相同金额
- 匹配条件：币种为 `USDT`、金额**完全相等**、交易时间落在订单的支付时间窗内
- 幂等：同一笔币安流水（`transactionId`）只会核销一次，重复轮询不会重复回调商户
- 无链上确认：命中流水后订单直接进入「已支付」并回调商户

## 已知限制

- **仅金额匹配**：付款时多打或少打金额都不会自动核销，订单会正常过期
- **无扫码标准**：收银台展示「收款 UID + 精确金额」并提供复制按钮，引导用户在币安 App 内手动转账
- 币安风控可能导致 API 失效，接口报错时可在后台日志（`logs/task.log`）查看
