# 币安 Pay 收款

通过**币安 Pay**（Binance Pay）收款：用户在币安 App 内直接向你的币安账号转账 USDT/USDC，
**零手续费、即时到账**（币安内部转账，不经过区块链，因此没有链上确认环节）。

本功能使用**个人只读模式**：只拉取你的收款流水，不涉及任何商户下单接口。

## 原理

币安 Pay 内部转账不会产生链上交易，所以传统的「扫块比对金额」无法使用。
本项目的做法与 [BinancePayTool](https://github.com/qianyubtc/BinancePayTool) 一致：

1. 收银台为每笔订单生成一个**唯一金额**（在订单金额上按原子精度递增，保证同一时刻不会有两笔订单金额相同）
2. 后台定时拉取币安收款流水，找到「金额完全相等且在订单支付时间窗内」的入账
3. 命中即视为支付成功，直接回调商户

## 开启步骤

### 1. 创建只读 API Key

登录币安官网 → 管理 → API 管理，创建一个**只读**权限的 API Key（无需开启提币权限），
记录下 `API Key` 与 `Secret`。

> 请注意：币安个人账号商户 API 已停止开放，本功能仅使用个人账号的 Pay 流水查询接口。
> 使用个人收款接口存在币安风控与合规风险，请自行评估后使用。

### 2. 后台填写凭证

进入 **后台 → 系统设置 → 基本设置**，填写：

| 配置项 | 说明 |
|---|---|
| 币安 Pay API Key | 上一步创建的 API Key |
| 币安 Pay API Secret | 上一步创建的 Secret；保存后后台显示 `******` 表示已保存，不改即保持原值 |
| 币安 Pay 接口地址 | 币安 API 基础地址，默认官方 `https://api.binance.com`，一般无需修改 |
| 币安 Pay 轮询间隔 | 流水扫描间隔（秒），**最低 10 秒**（接口权重限制），推荐 `30` |

填好后点击 **「测试币安 Pay 连接」**：用当前配置拉一次流水，成功会提示读到的流水条数，
Key/Secret 填错会直接报错，无需反复保存试探。

留空 API Key / Secret 即视为**未启用**，任务会空转不请求币安接口。
任务运行时对连续失败自动退避（最长 4 倍间隔），避免密钥错误时空烧接口权重。

### 3. 添加收款钱包

进入 **后台 → 钱包管理 → 新增钱包**：

- 交易类型：`USDT・Binance Pay`（收 USDT）或 `USDC・Binance Pay`（收 USDC）
- 钱包地址：填写你的**币安 UID**（纯数字，例如 `387453979`）

添加后该收款方式会自动出现在收银台的支付方式列表中。
收 USDC 就加 `USDC・Binance Pay` 那一行；两种币种可以各加一个（UID 相同也不冲突，
系统按「币种 + 金额」匹配入账）。

> ⚠️ **同一币种只能有一个启用中的币安 Pay 钱包**：一个 API Key 只能看到本账号的流水，
> 配置第二个启用中的同币种钱包会被后台拒绝（即使 UID 不同）。

## 工作原理细节

- 订单金额即指纹：同一 UID 下，等待支付/确认中的订单不会被分配到相同金额
- 匹配条件：币种与订单一致（`USDT` / `USDC`）、金额**完全相等**、交易时间落在订单的支付时间窗内
- 幂等：同一笔币安流水（`transactionId`）只会核销一次，重复轮询不会重复回调商户
- 无链上确认：命中流水后订单直接进入「已支付」并回调商户
- **过期单迟到款自动补收**：到期瞬间才付款的订单不会立刻作废——扫描窗口对齐链上任务的
  回溯时间（`订单回溯时间`，默认 3 小时），过期前已付、扫描晚到的流水仍会核销订单；
  过期后才付的款不会误核销，而是走下面的无主入账告警
- **无主入账告警**：流水窗口内找不到归属的 USDT/USDC 入账（金额打错、过期后付款等），
  会通过 Telegram 发送告警并写入日志（`logs/task.log` 搜索 `无主入账`），提醒人工核对；
  同一笔流水只告警一次
- 无需币安接口权重时绝不空扫：没有待收订单时不调用币安接口

## 付款金额打错了怎么办（收银台自助找回）

用户在币安 App 内实际转出的金额与订单不一致时（多转/少转），订单不会被自动核销。
此时**付款人**可以在收银台（等待支付页）展开「金额付错了？回填订单编号找回」：

1. 打开币安 App → 该笔转账的详情页，复制 **「订单编号」**（18 位数字）
2. 粘贴到收银台的回填输入框，点击「回填找回」
3. 系统核验该编号的入账流水（币种一致、未被其他订单使用、时间在订单窗口内）后即完成核销，
   **订单金额以实际到账为准**

核销动作受指纹保护（仅限本人页面操作）且每笔订单 30 秒内只能尝试一次。

## 其他收银台能力

- **我已完成支付**：付款后点击可触发一次即时扫描，通常 1～3 秒内即可到账翻绿
  （同一订单 15 秒内只触发一次，防止滥用接口权重）
- **打开币安 App**（实验性）：移动端收银台提供一键唤起币安 App 的按钮
  （`bnc://` 协议未公开文档，未能唤起时页面会提示手动打开）
- **过期页客服引导**：配置了 `payment_support_url`（基本设置 → 客服链接）后，
  过期/取消页会展示「联系客服」入口，方便打错金额的用户求助

## 已知限制

- **金额匹配优先，回填兜底**：金额不一致不会自动核销，需付款人按上述步骤回填订单编号，
  或管理员按无主入账告警人工处理
- **无扫码标准**：收银台展示「收款 UID + 精确金额」并提供复制按钮，引导用户在币安 App 内手动转账
- **打开币安 App 为实验功能**：`bnc://` 协议未经官方文档与全机型真机验证，唤起失败时请手动打开
- 币安风控可能导致 API 失效，接口报错时可在后台日志（`logs/task.log`）查看
